# KamenRider-plugin

> 基于 [TRSS-Yunzai](https://github.com/TimeRainStarSky/Yunzai) 的假面骑士图鉴查询与娱乐插件。

## 功能简介

| 指令 | 说明 |
| --- | --- |
| `#假面骑士 <名字>` | 图鉴查询，中文常见名或英文名均可（如 `Geats`、`电王`、`W`），返回图片卡片 |
| `#随机骑士` | 随机来一位假面骑士 |
| `#每日一骑` | 当日固定的一位骑士（全 Bot 当天相同） |
| `#骑士帮助` | 查看指令一览 |

大部分配置支持锅巴面板可视化修改与热加载（总开关 / 每日一骑开关 / 简介字数）。

## 安装方式

进入云崽根目录，克隆到 plugins 目录：

```bash
# Gitee
git clone --depth=1 https://gitee.com/aayhg/KamenRider-plugin ./plugins/KamenRider-plugin

# GitHub
git clone --depth=1 https://github.com/mldqzs/KamenRider-plugin ./plugins/KamenRider-plugin
```

安装后重启云崽即可。
